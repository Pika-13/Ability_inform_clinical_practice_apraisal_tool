# Ability to Inform clinical practice
*This repository contains project of metaresearch study, which is a systematic review of surgical RCT**

## Aims
### Assess shortcoming in pretrial planning, measured by report of 2 elements: STUDY DESIGN & ENDPOINT
### Assess clinical meaningfulness incorporation in pretrial planning:
#### 1) proportion of RCTs aiming for a MCID for the effect size
#### 2) proportion of RCTs interpretating results according to clinical relevance


## Content
You can find in the repository the following folders:

  **code**: 
  - Part_2_main_study_read_tidy_clean: R code to tidy, attribute values to each of the 4 criteria assessed + other outcomes
  - Part_3_pilot_study_read_tidy_clean_csv_table: R code to tidy, attribute values to each of the 4 criteria assessed
  - Part_4_For_pilot_and_final_merged_Generate_tables: generate results tables
  **database**: 
    - articles_167.csv: raw .csv file with 167 articles extracted from rayyan. contains metadata essentially (title, author, volume, doi)
    - database_pilot_v1: .csv file with 87 articles from pilot, contains the outcomes and assessment of each of 4 criteria
    - database_vapril27: .csv file with 167 articles from main study, contains the outcomes and assessment of each of 4 criteria
    - Pilot_87_original.xlsx: file with 87 studies (+ condensed format, same content than original)
    - Pilot_87_database.xlsx: file with 87 studies (original format)
  **output**:
    - Figure1._Flow_diagram_of_literature_review_2025_10_13_AF: docx file with PRISMA flow chart for pilot study
    - Process_of_Literature_search: search strategy for pilot
    - PRISMA_flowchart_2026_02_07: docx file with PRISMA flow chart for main study
    - **tables**: contains 2 docx results tables with 4 criteria + supp table with exploratory analyses
  **resources_endnote**:
    - citation_2024_19393.ris: ris formatted zotero studies published in 2024 found in CENTRAL
